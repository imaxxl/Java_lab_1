## Лабораторная работа № 1 — «Социальная сеть», вариант 7

Приложение на JavaFX: профили трёх типов, связи дружбы, загрузка и сохранение данных
в CSV, проверка значений и разбор ошибок файла.

Стек: Java 21, Gradle Kotlin DSL (Wrapper 8.10.2), JavaFX 21, JUnit 5.

Возможности:

- таблица профилей с загрузкой и сохранением CSV;
- редактирование только записей с `Editable`, архивный профиль открыт только для чтения;
- добавление обычных профилей и сообществ с проверкой введённых значений;
- ошибочные строки файла пропускаются, номер строки и код ошибки показываются в диалоге;
- чтение и запись файла выполняются в фоновом потоке, несохранённые изменения подтверждаются.

### Запуск

Нужен установленный JDK 21, Gradle ставить не нужно — Wrapper скачает сам.
Команды выполняются в каталоге `social-network-java`.

Windows, PowerShell:

```
.\gradlew.bat run
```

Linux / macOS:

```
./gradlew run
```

Тесты: `./gradlew --no-daemon clean test`.

### Структура

- `social-network-java/src/main/java/ru/university/socialnetwork/model` — профили, сообщество, дружба;
- `.../store` — хранилище с проверками уникальности и ссылок;
- `.../csv` — разбор и безопасное сохранение CSV;
- `.../gui` — окно приложения, форма редактирования, диалоги ошибок;
- `.../graph` — граф связей и поиск кратчайшей цепочки;
- `social-network-java/docs` — отчёт по лабораторной работе и скриншоты;
- `social-network-java/test.csv` — пример файла для демонстрации.
