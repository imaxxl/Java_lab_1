## Лабораторная работа № 1 — «Социальная сеть», вариант 7

Приложение на JavaFX: профили трёх типов, связи дружбы, загрузка и сохранение данных
в CSV, проверка значений и разбор ошибок файла.

Стек: Java 21, Gradle Kotlin DSL (Wrapper 8.10.2), JavaFX 21, JUnit 5.

### Запуск

Нужен установленный JDK 21, Gradle ставить не нужно — Wrapper скачает сам.
Команды выполняются в корне репозитория.

Windows, PowerShell:

```
.\gradlew.bat run
```

Linux / macOS:

```
./gradlew run
```

Тесты: `./gradlew --no-daemon clean test`.
Если Java не находится, укажите каталог JDK 21 в `JAVA_HOME`.

### Работа с приложением

Таблица показывает тип, ID, имя, город, год и дополнительные сведения.
Кнопки «Загрузить» и «Сохранить» работают с CSV, ошибочные строки попадают в отдельное окно.

- «Добавить» создаёт обычный профиль (`PROFILE`) или сообщество (`COMMUNITY`), архивный тип недоступен.
- «Изменить» активна только для редактируемых записей (`Editable`), удалённый профиль изменить нельзя.
- Переключение на другой файл и закрытие окна при несохранённых изменениях запрашивают подтверждение.
- Чтение, проверка и запись файла выполняются в фоновом потоке, окно при этом не зависает.

Порядок демонстрации: загрузить `test.csv`, показать заблокированную кнопку у удалённого профиля,
добавить профиль, изменить сообщество, попробовать повторный ID, сохранить файл и загрузить его снова.
Файл `src/main/resources/example.csv` содержит четыре корректные записи и три ошибки,
`example-quoted.csv` — пример с кавычками и разделителем внутри текста.

### Модель

| Класс | Editable | Назначение |
| --- | --- | --- |
| `Profile` | нет | общая неизменяемая база: ID, имя, город, год рождения |
| `EditableProfile` | да | обычный профиль, создаётся и редактируется в GUI |
| `DeletedProfile` | нет | архивная запись с причиной удаления, только чтение |
| `Community` | да | сообщество с описанием и ID администратора |

`Editable` — интерфейс с методом `validate()`, то есть контракт на редактирование, а не общий предок.
Поля профилей объявлены `final`, сеттеров нет: редактирование создаёт новый объект с прежним ID,
который заменяет запись в `ProfileRepository`. Дружба — неориентированная связь двух разных профилей.

Правила: ID положительные и уникальные, год от 1900 до текущего, имя и город обязательны,
администратор — существующий обычный профиль, текстовые поля однострочные.

### Формат CSV

UTF-8, разделитель `;`, обязательный заголовок, ровно восемь колонок:

```
type;id;name;city;birthYear;description;administratorId;reason
```

Типы записей: `PROFILE`, `DELETED`, `COMMUNITY`. Неиспользуемые колонки остаются пустыми.
BOM перед заголовком допускается. Поля с `;` или кавычками записываются в двойных кавычках,
внутренняя кавычка удваивается:

```
PROFILE;1;"Анна; Мария";Омск;2000;;;
DELETED;2;Пётр;Омск;1999;;;"Архив; навсегда"
COMMUNITY;3;Java Club;Москва;2020;"Java; Kotlin ""JVM""";1;
```

Ошибка в строке не прерывает загрузку: строка пропускается, а её номер и код попадают в результат:
`BAD_HEADER`, `BAD_CSV_FORMAT`, `WRONG_FIELD_COUNT`, `EMPTY_FIELD`, `BAD_NUMBER`,
`UNKNOWN_TYPE`, `DUPLICATE_ID`, `INVALID_VALUE`, `INVALID_REFERENCE`.

### Структура

- `src/main/java/ru/university/socialnetwork/model` — профили, сообщество, дружба;
- `.../store` — хранилище с проверками уникальности и ссылок;
- `.../csv` — разбор и безопасное сохранение CSV;
- `.../gui` — окно приложения, форма редактирования, диалоги ошибок;
- `.../graph` — граф связей и поиск кратчайшей цепочки;
- `src/test` — JUnit-тесты, интерфейс проверяется без открытия окна;
- `docs` — отчёт по лабораторной работе и скриншоты;
- `test.csv`, `test2.csv` — примеры файлов для демонстрации.

В `.github/workflows/java.yml` описан запуск `clean test` на Java 21 после каждого push.
